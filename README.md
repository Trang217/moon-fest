# 🌙 Moon Fest 🏮

**Moon Fest** is a small Mid-Autumn Festival shop project inspired by Vietnamese traditions. ✨

The shop focuses on traditional and festive products for celebrating **Tết Trung Thu**.

## 🛍️ Products

- ⭐ **Star Lanterns** – traditional Vietnamese _đèn ông sao_
- 🦚 **Peacock Scarves** – colorful _khăn công phượng_
- 🏮 **Mid-Autumn Decorations** – decorative paper and festive accessories

## ✨ About the Project

Moon Fest is currently being developed as a frontend e-commerce project.

The goal is to create a warm, colorful and nostalgic shopping experience inspired by Vietnamese Mid-Autumn Festival memories. 🌕🥮

## 🛠️ Tech Stack

- ⚛️ React
- 🔷 TypeScript
- ⚡ Vite
- 🎨 CSS
- 🔍 ESLint
